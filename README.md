# Northstar — Operations workspace

A static, browser-local project and task workspace published with GitHub Pages.

## Use

Open the Pages site and add projects and tasks. The workspace supports task priorities, statuses, due dates, project association, dependencies, blocker notes, tags, search, filters, a Kanban board, timeline, notes, and an on-demand weekly review. Export a JSON backup to move data to another browser; import replaces the current local workspace after confirmation.

## Data and privacy

This static GitHub Pages edition has no backend and no live connectors. Projects, tasks, notes, and review reports stay in the current browser's `localStorage`; they do not sync across devices, Wabi, GitHub, Gmail, Drive, Calendar, Notion, or Slack. The public repository contains only generic app source and documentation, not private account data. Keep exported JSON backups private.

For connected-source snapshots and Wabi-backed persistence, use the separate Business Operations Command Center mini-app in Wabi.
